ข้อกำหนดข้อมูลและสิทธิ์

  • ไม่มีการดึงข้อมูลครูหรือนักเรียนจริงจาก Golden Sheet
  • ข้อมูลจำลองอยู่เฉพาะ Session ของแท็บ ไม่ใช่ Cloud Database
  • ตรวจชนกันของครูหลัก/ครูร่วม ห้อง และสถานที่
  • หน่วยชั่วโมงคำนวณจากนาทีจริงทุกครั้ง
  • สอนแทนจริงต้องยืนยันการลาและได้รับ Human Approval
  • การ Deploy แอปจริงและการประกาศตารางสอนเป็นคนละ Release Gate
